## 1. 产品概述

### 1.1 产品定位
**AceProxy** — 面向印尼消费者的跨境代采平台。用户通过 AceProxy 购买中国工厂直供商品，享受比本地零售低 30-60% 的价格，全程 AI 质检 + 端到端物流追踪。

### 1.2 核心价值主张
- 🏭 **工厂直供**：跳过多层中间商，价格碾压本地零售
- 👁️ **AI 质检**：VisionQC 2.0 自动对比 1688 规格与仓库实拍，色差/瑕疵零容忍
- 🔄 **转售中心**：买错不慌，Resale Hub C2C 转售赚回 Ace Credits
- 💬 **AI 管家**：24/7 智能客服，自动搜货比价，多语言支持

### 1.3 目标用户

| 角色 | 描述 | 核心需求 |
|------|------|----------|
| 🛍️ **个人消费者** | 雅加达白领，追求性价比 | 找便宜好货、安全支付、物流追踪 |
| 💰 **小微批发商** | 印尼电商卖家（Shopee/Tokopedia） | 批量采购、成本核算、转卖利润 |
| 🤝 **团长/Partner** | 社区团购组织者 | 邀请裂变、佣金结算、订单管理 |

## 2. 用户场景与故事

### 场景 A：个人消费者首次购物
> "Saya lihat baju koko di toko Rp 450rb, tapi teman bilang AceProxy bisa dapat Rp 99rb. Gimana caranya?"

1. 打开 AceProxy App → 看到热销商品列表
2. 点击"Smart Sourcing" → 粘贴 TikTok/Shopee 链接 → AI 自动搜同款
3. 看到匹配结果（价格便宜 70%）→ 加入购物车
4. 用 GoPay 支付 → 等待 7-10 天 → 收到包裹 ✓

### 场景 B：小微批发商批量采购
> "Saya jualan mukena di Shopee, butuh 50 pcs dengan harga bagus."

1. 登录 Partner 账号 → 进入 Wholesale 专区
2. 搜索"旅行 mukena"→ 对比 3 家供应商报价
3. 下单 50 件 → 自动生成佣金报表
4. 收货后通过 Resale Hub 出清尾货 → 提现佣金 ✓

### 场景 C：AI 管家智能导购
> "Cariin kado buat lebaran, budget Rp 100rb-an, yang unik."

1. 打开 AI Steward 聊天 → 输入需求
2. AI 自动调用 searchProducts + searchByPrice 工具
3. 返回 3 个推荐：LED 月亮灯 (Rp 150k)、智能念珠戒指 (Rp 180k)、丝绸头巾 (Rp 99k)
4. 用户点击推荐卡片 → 跳转商品详情 → 下单 ✓
