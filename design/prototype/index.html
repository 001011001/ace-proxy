🔧 如何导入 Figma

1️⃣
创建设计令牌

在 Figma 中创建 Color Styles 和 Text Styles，使用 AceProxy_Figma_Design_Specification.md 中的 HEX 值和字体参数

2️⃣
构建组件库

按规范文档创建 Auto Layout 组件，设置 Variants 覆盖所有交互状态（Default/Hover/Active/Focus/Disabled）

3️⃣
设计页面

参照 HTML 原型和页面规范，在 Figma 中搭建高保真页面。每个页面至少设计 Desktop + Mobile 两个断点

4️⃣
创建原型连线

按照用户流程文档配置 Prototype connections，添加 Smart Animate 过渡效果
